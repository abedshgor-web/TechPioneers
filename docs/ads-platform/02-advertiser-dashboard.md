# 02 — لوحة المعلِن (Advertiser Dashboard)

**الهدف:** تمكين المعلِن من إنشاء وإدارة حملاته، استهداف جمهوره، ومراقبة الأداء — من واجهة واحدة سهلة.

---

## 1. هرمية الكيانات الإعلانية

```
الحساب (Advertiser Account)
└── الحملة (Campaign)         ← الهدف + الميزانية + الجدولة
    └── المجموعة الإعلانية (Ad Group)   ← الاستهداف + المزايدة
        └── الإعلان (Creative/Ad)        ← الأصل + رابط الوجهة
```

- **الحملة:** تحدد الهدف (نقرات/ظهور)، الميزانية اليومية والإجمالية، تاريخ البداية/النهاية.
- **المجموعة الإعلانية:** تحدد *من* يرى الإعلان (الاستهداف) و*كم* تدفع (المزايدة).
- **الإعلان:** المحتوى المرئي الفعلي.

---

## 2. الصفحة الرئيسية للوحة (Overview)

عند الدخول، يرى المعلن لمحة سريعة:

- **بطاقات إحصائية (StatCards):** الرصيد الحالي، الإنفاق اليوم، الانطباعات، النقرات، CTR.
- **رسم بياني للأداء:** الإنفاق/النقرات عبر آخر 7/30 يوماً.
- **حالة الحملات النشطة:** جدول مختصر (اسم، حالة، إنفاق، نقرات).
- **تنبيهات:** «رصيدك منخفض»، «حملة قيد المراجعة»، «حملة انتهت».

---

## 3. تدفّق إنشاء الحملة (Campaign Wizard)

معالج متعدد الخطوات لتقليل التعقيد:

| الخطوة | المدخلات |
|--------|----------|
| **1. الهدف** | نقرات (Traffic) — في الـ MVP. لاحقاً: تحويلات، وعي. |
| **2. الاستهداف** | الموقع، اللغة، الجهاز، (لاحقاً: العمر، الاهتمامات). |
| **3. الميزانية والجدولة** | ميزانية يومية + إجمالية، تاريخ البداية/النهاية، الوتيرة. |
| **4. المزايدة** | يدوية (CPC أقصى) أو تلقائية. |
| **5. الإعلان (Creative)** | رفع صورة، عنوان، نص، رابط الوجهة، معاينة حية. |
| **6. المراجعة والإطلاق** | ملخص + تأكيد الرصيد الكافي + إرسال للمراجعة. |

**قواعد التحقق:**
- الميزانية الإجمالية ≤ الرصيد المتاح (أو تنبيه بالشحن).
- رابط الوجهة صالح (HTTPS).
- أبعاد/حجم الصورة ضمن الحدود المسموحة.
- المحتوى يمر على فلتر أولي قبل المراجعة البشرية.

---

## 4. الاستهداف (Targeting)

### المرحلة الأولى (MVP)
- **الموقع الجغرافي:** دولة / مدينة (من IP geolocation).
- **اللغة:** لغة المتصفح/الجهاز.
- **الجهاز:** سطح مكتب / جوّال / لوحي.

### مراحل لاحقة
- **العمر والجنس** (بيانات طرف أول من تسجيل المستخدمين).
- **الاهتمامات** (مشتقة من السلوك على الناشرين).
- **إعادة الاستهداف** (Retargeting) عبر pixel.
- **القوائم المخصصة** (رفع جمهور).

> ملاحظة خصوصية: يُفضَّل بيانات الطرف الأول وتجنّب التتبّع عبر المواقع قدر الإمكان (راجع `05-admin-panel.md` و`06`).

---

## 5. محرر الإعلان (Creative Editor)

- رفع صورة (سحب وإفلات) مع قصّ/معاينة.
- حقول: العنوان (≤ 40 حرف)، النص (≤ 90 حرف)، اسم العلامة، CTA.
- **معاينة حية** لشكل الإعلان في الأماكن المختلفة (Placements).
- التحقق الفوري من الطول والأبعاد.
- حفظ كمسودة قبل الإرسال.

---

## 6. إدارة الحملات

- **قائمة الحملات:** بحث، فرز، فلترة بالحالة.
- **الحالات:** مسودة، قيد المراجعة، نشطة، متوقفة مؤقتاً، منتهية، مرفوضة.
- **إجراءات سريعة:** إيقاف/تشغيل، تعديل الميزانية، تكرار (Duplicate)، أرشفة.
- **التعديل المباشر:** تغيير الميزانية والمزايدة دون إعادة المراجعة (إذا لم يتغيّر المحتوى).

---

## 7. مراقبة الأداء داخل اللوحة

- رسوم بيانية تفاعلية (إنفاق، انطباعات، نقرات، CTR، CPC الفعلي).
- تفصيل حسب الحملة/المجموعة/الإعلان.
- مقارنة الفترات الزمنية.
- روابط مباشرة إلى التقارير المفصّلة (`04-reports-and-analytics.md`).

---

## 8. الجوانب التقنية

- جميع الصفحات محمية بـ JWT (دور: `advertiser`).
- نقاط API رئيسية:
  - `GET/POST /api/campaigns`
  - `GET/POST /api/campaigns/:id/adgroups`
  - `GET/POST /api/adgroups/:id/ads`
  - `PATCH /api/campaigns/:id/status`
- التحقق من الرصيد عند الإطلاق وبشكل دوري أثناء التشغيل.
- رفع الأصول إلى تخزين S3-compatible، حفظ الروابط في قاعدة البيانات.

## 9. معايير القبول

- [ ] إنشاء حملة كاملة في ≤ 10 دقائق.
- [ ] منع الإطلاق عند عدم كفاية الرصيد مع توجيه للشحن.
- [ ] تعديل الميزانية ينعكس على الإنفاق خلال دقائق.
- [ ] المعاينة الحية تطابق العرض الفعلي.
- [ ] كل التغييرات على المحتوى تُعيد الحملة لحالة «قيد المراجعة».
