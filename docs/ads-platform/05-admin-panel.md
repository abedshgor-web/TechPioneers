# 05 — لوحة المدير (Admin Panel)

**الهدف:** منح فريق التشغيل تحكماً كاملاً في المستخدمين، مراجعة الإعلانات، مكافحة الاحتيال، وإدارة المحتوى والإشعارات.

---

## 1. الأدوار والصلاحيات (RBAC)

| الدور | الصلاحيات |
|-------|-----------|
| **Super Admin** | كل شيء، بما فيه إدارة المسؤولين والإعدادات المالية. |
| **Moderator** | مراجعة واعتماد/رفض الإعلانات فقط. |
| **Support** | عرض حسابات المستخدمين، مساعدة، دون تعديل مالي. |
| **Finance** | المعاملات، الاسترداد، المطابقة المالية. |

- كل إجراء حساس يتطلب صلاحية صريحة ويُسجَّل في **سجل التدقيق (Audit Log)**.
- المصادقة الثنائية (2FA) إلزامية لحسابات الإدارة.

---

## 2. إدارة المستخدمين والمعلنين

- **قائمة المستخدمين:** بحث، فلترة (الحالة، تاريخ التسجيل، الإنفاق).
- **تفاصيل المستخدم:** البيانات، الحملات، الرصيد، سجل المعاملات، النشاط.
- **الإجراءات:** إنشاء، تعديل، تعليق (Suspend)، حظر، حذف.
- **التحقق (KYC):** للحسابات عالية الإنفاق أو حسب المتطلبات التنظيمية.
- **انتحال الجلسة (Impersonation):** دخول كـ مستخدم لأغراض الدعم (مُسجَّل بصرامة).

---

## 3. مراجعة الإعلانات (Ad Moderation)

أهم وظيفة لحماية المنصة والمستخدم النهائي:

- **طابور المراجعة:** الإعلانات الجديدة/المعدّلة بحالة «قيد المراجعة».
- **فلتر آلي أولي:** كشف الكلمات المحظورة، فئات حساسة، روابط ضارة.
- **مراجعة بشرية:** اعتماد/رفض مع سبب.
- **سياسات المحتوى:** قواعد واضحة (لا محتوى مضلل/مخالف/احتيالي/ينتهك حقوق الملكية).
- **إعلانات مالية:** تدقيق إضافي (تحذيرات المخاطر، تراخيص) — مهم بالنظر لطبيعة TechPioneers.
- **القوائم:** سوداء (نطاقات/كلمات محظورة) وبيضاء (معلنون موثوقون → مراجعة أسرع).

**الحالات:** قيد المراجعة → معتمد / مرفوض (مع سبب) / يحتاج تعديل.

---

## 4. مراقبة النشاط ومكافحة الاحتيال

- **لوحة مراقبة لحظية:** الحملات النشطة، الإنفاق، الأحداث.
- **كشف الشذوذ:**
  - معدلات نقر شاذة (Click fraud).
  - حركة من IP/أجهزة مشبوهة.
  - أنماط شحن/استرداد مريبة.
- **إجراءات:** تجميد حملة/حساب، حجز رصيد، طلب تحقق.
- **تنبيهات آلية** لفريق الاحتيال عند تجاوز عتبات محددة.
- سجل كامل لكل قرار للمراجعة لاحقاً.

---

## 5. إدارة المحتوى (CMS خفيف)

- التحكم في محتوى **صفحة الهبوط** (العناوين، الشهادات، الأسعار، FAQ).
- إدارة **البانرات/الإعلانات الترويجية** داخل المنصة.
- إدارة الصفحات القانونية (الشروط، الخصوصية).
- دعم تعدد اللغات لكل محتوى قابل للتحرير.

---

## 6. الإشعارات والرسائل

- **إشعارات النظام للمعلنين:** رصيد منخفض، حملة معتمدة/مرفوضة، انتهاء حملة.
- **بث رسائل جماعية** (تحديثات، صيانة) عبر البريد/داخل التطبيق.
- **صندوق وارد إداري:** استقبال طلبات الدعم والتنبيهات الداخلية.
- قوالب رسائل متعددة اللغات.
- تكامل مع مزود بريد (مثل Postmark/SES) وإشعارات داخل التطبيق.

---

## 7. الإعدادات والتقارير الإدارية

- **إعدادات عامة:** نماذج التسعير، الحدود الدنيا للشحن، العملات.
- **تقارير المنصة:** الإيرادات، عدد المعلنين النشطين، الإنفاق الكلي، معدلات الرفض.
- **سجل التدقيق (Audit Log):** كل إجراء إداري مع المنفّذ والوقت والتفاصيل.

---

## 8. الجوانب التقنية

- مسارات محمية بدور `admin`/`moderator` عبر middleware الصلاحيات.
- نقاط API:
  - `GET /api/admin/users`, `PATCH /api/admin/users/:id`
  - `GET /api/admin/ads/review`, `POST /api/admin/ads/:id/decision`
  - `GET /api/admin/fraud/alerts`
  - `GET/PUT /api/admin/content/*`
  - `POST /api/admin/notifications/broadcast`
- جداول: `audit_logs`, `moderation_decisions`, `fraud_alerts`, `cms_blocks`.

## 9. معايير القبول

- [ ] لا يصل إعلان للعرض دون اعتماد (افتراضياً).
- [ ] كل إجراء إداري حساس مُسجَّل في Audit Log.
- [ ] تعليق حساب يوقف حملاته فوراً.
- [ ] تنبيهات الاحتيال تُطلق عند تجاوز العتبات المحددة.
- [ ] 2FA مفعّلة وإلزامية لكل حسابات الإدارة.
