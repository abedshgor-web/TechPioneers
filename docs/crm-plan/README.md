# 📋 خطة بناء نظام CRM متعدد المستأجرين (Multi-tenant SaaS)

مشروع **جديد ومستقل بالكامل** لبناء نظام CRM سحابي موجّه للشركات (B2B)، ينافس كبار اللاعبين (Salesforce / HubSpot / Zoho / Pipedrive).
كل عمل تجاري يحصل على **مستأجر (Tenant)** معزول، عبر **تسجيل ذاتي** → **تجربة مجانية ١٤ يوماً** → **اشتراك شهري مدفوع**.

> 🟡 **الحالة العامة:** التخطيط قيد الإكمال. هذا الفهرس وثيقة حيّة تُحدَّث تلقائياً.

## 📌 الركائز المعتمدة

- **تعدد المستأجرين:** نمط Pool + PostgreSQL Row-Level Security (مسار ترقية إلى Schema/Silo للـ Enterprise).
- **Tech Stack:** Next.js · NestJS · PostgreSQL · Redis/BullMQ · Typesense · Claude (Haiku/Sonnet) · Stripe Billing.
- **الأمن:** عزل متعدد الطبقات + مصادقة صارمة + خارطة امتثال من ٥ مراحل (GDPR → SOC 2 → ISO 27001).
- **التمايز:** تعريب كامل + RTL · أقصى تسهيلات للعميل · AI جوهري · سعر وسهولة استخدام تنافسية.
